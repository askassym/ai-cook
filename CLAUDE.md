# Правила проекта «AI-повар»

## Общение
- Автор проекта — новичок в программировании.
- Объясняй каждый шаг простыми словами на русском языке.
- Перед незнакомыми командами коротко объясняй, что они делают.

## Стек
- Next.js (App Router) + Tailwind CSS.
- Деплой на Cloudflare Workers через vinext: `npm run deploy:vinext`.
  Ключ на Cloudflare — секрет воркера `GEMINI_API_KEY` (не в коде, не в git).
- Код — публичный репозиторий на GitHub.
- ИИ: Gemini API от Google.

## Безопасность
- Все секреты (ключи, пароли) хранятся только в `.env.local`.
- `.env.local` обязательно указан в `.gitignore` и никогда не попадает на GitHub.
- Ключ Gemini (`GEMINI_API_KEY`) используется только на сервере (в серверных маршрутах `/api/...`).
  Никогда не используй его в клиентском коде и не добавляй префикс `NEXT_PUBLIC_`.

## Дневник сборки
После каждой задачи дописывай запись в `BUILD_LOG.md` в формате:

```
## ГГГГ-ММ-ДД — краткое название задачи
**Промпт:** что попросил автор
**Что изменено:** какие файлы и что в них сделано
**Как проверить:** шаги для проверки
```

Не удаляй и не переписывай старые записи в `BUILD_LOG.md`.
