# 👩‍🍳 AI-повар — «Что приготовить?»

Веб-приложение, которое придумывает рецепты из продуктов, которые уже есть дома.
Отмечаешь продукты, выбираешь кухню и время — через несколько секунд получаешь 3 рецепта с пошаговыми инструкциями.

**Попробовать:** https://ai-cook.kasym-askerbekov.workers.dev

## Для кого

Для всех, кто стоит перед холодильником и не знает, что приготовить: студенты, родители, все, кто не хочет лишний раз идти в магазин.

## Что умеет

- **Выбор продуктов:** 12 кнопок (курица, рис, яйца, картофель и др.) + поле для своего продукта.
- **Настройки:** кухня (казахская, русская, итальянская, азиатская, европейская, кавказская или любая), время (до 15 / 30 / 60 минут), порции (1–6).
- **3 рецепта карточками:** время, сложность, калории на порцию, ингредиенты с количеством, что докупить, пошаговые инструкции и совет повара.
- Понятные сообщения об ошибках и защита от двойного нажатия.

## Как это работает

```
Браузер (страницы и кнопки)
   │  продукты, кухня, время, порции
   ▼
Сервер /api/generate (Cloudflare Workers) — хранит ключ Gemini
   │  промпт «придумай 3 рецепта, ответ в JSON»
   ▼
Gemini API (Google) — придумывает рецепты
   │  JSON с рецептами
   ▼
Браузер показывает карточки
```

Ключ Gemini хранится только на сервере, браузер его не видит. Если модель Gemini перегружена, сервер сам пробует запасные модели.

## Стек

- [Next.js](https://nextjs.org) (App Router) + [Tailwind CSS](https://tailwindcss.com)
- [Gemini API](https://ai.google.dev) — модель `gemini-3.8-flash` (запасные: `gemini-flash-latest`, `gemini-3.5-flash-lite`)
- Хостинг: [Cloudflare Workers](https://workers.cloudflare.com) через [vinext](https://github.com/cloudflare/vinext)
- Код написан с помощью [Claude Code](https://claude.com/claude-code) — дневник сборки в [BUILD_LOG.md](BUILD_LOG.md)

## Запуск у себя на компьютере

1. Установи [Node.js](https://nodejs.org) (версия LTS).
2. Скачай проект и установи зависимости:
   ```bash
   git clone https://github.com/askassym/ai-cook.git
   cd ai-cook
   npm install
   ```
3. Получи бесплатный ключ на [aistudio.google.com](https://aistudio.google.com) и создай файл `.env.local`:
   ```
   GEMINI_API_KEY=твой-ключ
   ```
4. Запусти:
   ```bash
   npm run dev
   ```
5. Открой http://localhost:3000

## Публикация на Cloudflare

```bash
npm run deploy:vinext
```

Ключ добавляется в Cloudflare отдельно: воркер `ai-cook` → **Settings → Variables and Secrets** → Secret `GEMINI_API_KEY`.

```
app/
  page.js                 — лендинг «/»
  app/page.js             — приложение «/app»
  api/generate/route.js   — сервер: запрос к Gemini
  layout.js, globals.css  — общий каркас и цвета
BUILD_LOG.md              — дневник сборки
```

## Безопасность

- `.env.local` в `.gitignore` — ключ никогда не попадает на GitHub.
- Не вводи в приложение личные данные: на бесплатном тарифе Google может использовать запросы для улучшения своих продуктов.
